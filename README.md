Java Core & Advanced Course Syllabus
A structured overview of core concepts, object-oriented principles, multithreading, and modern Java features.

📌 Part 1: Core Fundamentals & OOPs
-->JVM ArOOPs Fundamentals: Classes, objects, method overloading, encapsulation, static members, and the this reference.
-->Language Components: Data types, type casting, bitwise & logical operators, control flow loops and switch statements.
-->OOPs Fundamentals: Classes, objects, method overloading, encapsulation, static members, and the this reference.   
-->Arrays & Strings: 1D/2D/Jagged arrays, String Constant Pool (SCP) immutability, StringBuilder, and StringBuffer.

📌 Part 2: Advanced OOPs, Concurrency & Stream API
-->Advanced OOPs: Constructor chaining (this(), super()), inheritance, method overriding, access modifiers, abstract classes, and interfaces.
-->Special Features: Enums, inner/anonymous classes, wrapper classes, autoboxing, functional interfaces, and Lambda expressions.
-->Exception Handling: try-catch-finally, exception hierarchy, custom exceptions, throw vs throws.
-->Multithreading: Thread creation (Thread, Runnable), lifecycle states, race conditions, and synchronized blocks.
-->Collections & Streams: List, Set, Map interfaces, object sorting via Comparable/Comparator, and functional stream operations (filter, map, collect).
